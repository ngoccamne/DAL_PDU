DAL_PDU software design

Purpose

DAL_PDU is the power distribution unit board of the IGRVT-50 PC104 stack. The current ATmega128A firmware controls a TRANS eFuse, heartbeat LED, and TPS55287 variable output; it offers text commands on UART0 and the software console, plus a Modbus RTU register subset on USART1. The broader design calls for power telemetry, fault logging, and a dual-bank bootloader; those features are not yet implemented.

Start with Current firmware architecture for implemented modules and runtime flow, and Current command reference for commands available today. The requirements and use-case pages also describe planned features.

Key assumptions carried through every page

  1. Hardware blocker IF-001 (RS-232 driver/receiver reversed) is corrected before any firmware bring-up. The console is the software UART on PE3/PE4 (MCU-001, decided); see Hardware overview.
  2. The ATmega128A has exactly two hardware USARTs (USART0 on PE0/PE1, USART1 on PD2/PD3). All three required serial channels (PC104 RS-232, local console, RS-485/Modbus) must be allocated across those two USARTs plus one software (bit-banged) UART — see Serial resource allocation.
  3. The implemented Modbus map and ASCII commands are described on the current-firmware pages. Additional registers and commands in the requirements remain design targets.
