Modbus RTU implementation

The ATmega128A runs a Modbus RTU slave at the configured address (1 by default) and baud (9600 by default), 8N1 on USART1. RX is PD2, TX is PD3, and PD5 drives the RS485 direction line (high to transmit). Timer1 supplies the RTU silence interval. FreeMODBUS is a submodule under firmware/DAL_PDU/DAL_PDU/src/dev/M4_MiddleWare/ThirdParty/freemodbus/. Clone with git submodule update --init before building.

Addresses below use conventional one-based Modbus notation. Subtract one for masters that expect zero-based request offsets: coil 00002 has offset 1. Unsupported addresses return an illegal address exception. Other addresses in the design draft remain reserved.

Events and clock

The OBC reads an event in two steps. Write 40050 with the sequence number wanted (0 for the newest). Then read 30041–30047. Poll 30041 alone to see when a new event arrives, since it changes with each event. The clock is set with 40040–40041 and read with 30039–30040. Both use the same clock as the console time command. Check 30048 for the clock source: RESTORED means the time came from the last checkpoint and is approximate until the OBC sets it. The clock is checkpointed to EEPROM every 15 minutes.

Scheduling

The Modbus port is polled by a 5 ms task, not by the main loop. Each run calls eMBPoll twice, so a request is answered within about one period, which is 5 ms plus the length of the other tasks in that pass. The task also checks in with the watchdog (200 ms timeout). A request is a single frame, and the master waits for the reply, so polling every 5 ms is well inside any normal master response timeout. Keep any single task well under the 200 ms watchdog timeout, since a long task delays the Modbus reply.

Coils (FC 01/05/15)

Address Name Read value and write behavior
00001 VOUT_ENABLE Actual TPS55287 enable bit. Enabling powers TRANS on first if it is off and confirms the chip answers; still refused if a fault input is active. Disabling never powers TRANS on. Reads do not clear TPS fault flags.
00002 TRANS_BRANCH_ENABLE Actual TRANS eFuse output. A fault or a latched fault rejects enable. Disabling TRANS also requests VOUT off.
00003 CLEAR_FAULT_LATCH Read: 1 while any fault is latched. Write 1 to clear the latch in internal EEPROM. Write 0 does nothing. The latch does not enable TRANS.
00010 HEARTBEAT_ENABLE LED blinking enable. Applies to the NORMAL pattern only. Fault and warning indications always show.

Coils 00001 and 00002 can be read or written together. In a two-coil write, bit 0 is VOUT and bit 1 is TRANS. Enabling VOUT while disabling TRANS is rejected. Enabling both turns TRANS on first; a failed VOUT enable rolls back a newly enabled TRANS branch.

40001 VOUT_SETPOINT_MV R/W Commanded setpoint in mV, read from system data. 0xFFFF until a setpoint is commanded since reset. Same value as input 30023. A write powers TRANS on first if it is off and confirms the chip answers, then feedback mode and voltage range determine whether it is accepted.
40020–40021 LED_ON_MS R/W Unsigned 32-bit milliseconds, high word first.
40022–40023 LED_OFF_MS R/W Unsigned 32-bit milliseconds, high word first.
40030 MODE_REQUEST R/W Read: mode (0 NORMAL, 1 MANUAL, 2 WARNING, 3 ERROR). Write 0 to request NORMAL, 1 to request MANUAL. Refused in ERROR.
40031 LIMIT_TEMP R/W Over-temperature limit in tenths of a degree C, signed. Range -400 to 1250. Stored in internal EEPROM.

40103 FW_PATCH Read only Patch version; currently 0.
40104 CPU_MHZ Read only CPU clock in MHz; currently 12.
40105 SLAVE_ADDRESS Read only Active RTU slave address, from the configuration. Set with config set address; applies at the next boot.
40106 BAUD_RATE Read only Active RTU baud rate, from the configuration (1200 to 38400). Set with config set baud; applies at the next boot.
40107–40108 FW_BUILD Read only Build code, high word first. Bit 28 is the dirty flag. Bits 0 to 27 are the short git commit.

Read the seven-word identity block with FC 03 starting at 40100 (request offset 99). Writes to that block are rejected. Requests cannot span gaps between register groups. Both LED periods must be nonzero.

The TRANS application checks both fault pins every 6 ms and switches the eFuse off if either is active. The callbacks use SystemData for shared values, AppPower_SetTrans/AppPower_EnsureRegulatorOn for TRANS, and the TPS55287 BSP for VOUT. Coil 00001 (single write) and holding register 40001 both call AppPower_EnsureRegulatorOn before touching the TPS55287, so an OBC does not need to write coil 00002 first; the two-coil write at 00001 still handles VOUT and TRANS together explicitly.

The address and baud rate are fixed; the draft configuration registers are not implemented. Hardware revision and serial number have no defined source in this firmware. PD5 as the direction pin is confirmed on the board; verify its polarity and RX/TX timing on hardware.

The AVR project compiles upstream mbrtu.c through the local M2_BSP/Modbus/mbrtu_avr.c wrapper. That wrapper suppresses one unused STM32-only CRC temporary warning while keeping the FreeMODBUS submodule clean.
